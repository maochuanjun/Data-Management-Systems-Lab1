# 在线问卷系统（MongoDB + Go）

本项目提供问卷创建、发布、填写、条件跳转、题库管理和结果统计。后端用 Go，数据保存在 MongoDB，网页使用原生 HTML/CSS/JavaScript。程序不依赖关系数据库或现成问卷系统。

## 功能

- 注册、登录；用户只能管理自己创建的问卷和查看对应统计。
- 创建问卷、添加题目、设置截止时间，发布后通过 `/survey/{id}` 分享，必要时关闭。
- 三类题型：单选、多选、填空（文本或数字）；支持必答、选择数量、字数、数值范围和整数校验。多选的最少与最多数量设为同一值时，可要求恰好选择该数量。
- 根据单选、多选及数字填空的答案执行问卷中配置的条件跳转。
- 登录后填写，按设置匿名提交或限制同一账号重复填写；每次答卷独立存入 MongoDB。
- 创建者查询整卷或单题统计，包括选项次数、数字平均值和填空内容。
- 保存可复用题目，按用户名共享；在多份问卷中选择指定版本。
- 从任一历史版本派生新版本或恢复内容，保留来源关系；已有问卷继续使用保存时的快照。
- 创建个人题库，添加、移除或替换固定版本；查看题目的问卷使用情况。
- 按题目版本汇总自己创建的多份问卷，查看数值分布和分页答案。共享题目不会公开其他用户的答卷。
- 填写时返回上一题保留页面内输入，提交前显示答案概览；已提交且禁止重复的账号在进入填写页时收到提示。
- 编辑离开时提示未保存内容，新增跳转规则保持展开；新配置拒绝相同选项文字，错误以题号定位。

第二阶段在第一阶段基础上增加题目复用、指定用户共享、不可变版本、历史恢复、多版本并存、使用情况、个人题库和跨问卷统计。题目作者可查看全局引用数量，引用问卷的具体明细仍限本人；跨问卷回答统计也只覆盖本人创建的问卷，并按具体版本分别计算。题目共享、题库固定项和问卷内容快照分别管理，更新题目或撤销共享不会改写已保存的问卷内容。

共享名单和题库编辑均有修订号冲突检查；题目详情页保护未保存草稿。第二阶段的题目创建、问卷题目另存、题库创建/保存/删除与选题预览、跨问卷统计切换等操作检查发起页面或当前查询是否仍有效，避免已离开页面的迟到响应重新导航或覆盖当前提示。八项需求的对应范围见 [第二阶段实施与兼容计划](documentation/phase2-plan.md)，本次交付结果见 [测试说明的最新验收记录](documentation/testing.md)。

## 运行

运行服务需要 Go 1.26+、Make 和 MongoDB 8.0。使用默认本地数据库时还需要 Docker 与 Docker Compose；使用已有数据库时可直接指定连接地址。默认启动方式：

~~~sh
make run
~~~

浏览器打开 <http://127.0.0.1:8080>。Makefile 会先启动本地 MongoDB 并等待其健康，再运行 Go 服务；默认数据库为 `questionnaire_lab1`，MongoDB 在主机 `127.0.0.1:27018`。

使用已有数据库时可覆盖连接地址：

~~~sh
MONGO_URI='mongodb://127.0.0.1:27017' MONGO_DB=my_survey make run
~~~

填写者必须先登录。问卷允许匿名且填写者本次选择匿名提交时，答卷不直接保存用户 ID；本次未选择匿名时仍保存用户 ID。禁止重复填写时，匿名与实名提交共用账号级去重规则。

## 测试

核心测试还需要 Node.js，因为 `make test` 和 `make verify` 都会运行 JavaScript 前端测试。集成测试及 E2E 默认启用 Go 的 `-race` 检测，需要可用的 C 编译工具链和支持 race 检测的 Go 环境。

~~~sh
make test          # Go 单元测试与 JavaScript 前端测试
make integration   # MongoDB 集成测试
make verify        # 以上核心测试、go vet、构建
~~~

可选浏览器端到端测试还需要 npm、Playwright 和 Chromium：

~~~sh
npm ci
npx playwright install chromium
make e2e
~~~

测试按领域单元、真实 MongoDB 集成、前端交互和浏览器端到端四层组织，全部放在 `tests/`。执行记录和覆盖范围见 [测试说明](documentation/testing.md)。
