## 二、AI 输出出现的问题

| 问题 | 发现方式 | 修正结果 |
| --- | --- | --- |
| 匿名填写语义被误解 | 对照需求中“填写者须先登录” | 统一为先登录、提交时可选匿名 |
| 保存草稿的异步结果覆盖继续输入 | 模拟保存请求延迟 | 保存时锁定编辑器，并补前端回归 |
| 不可完成的必答题可能被发布 | 构造无合法答案的范围 | 在业务层拒绝不可能满足的约束 |
| 特殊题目 ID 导致前端答案异常 | 使用 `__proto__` 等题目 ID | 用无原型对象保存答案，补测试 |
| 聚合原始长文本存在 16 MiB BSON 风险 | 大量长文本统计测试 | 改为汇总聚合加原文分页 |
| 浏览器测试受异步加载和下拉框名称影响 | 实际 Chromium E2E 失败记录 | 等待 DOM 加载完成，为选择器设置 `aria-label` 后复测 |

## 三、AI 与个人工作的边界

使用者提出项目范围、技术栈、扩展性、测试组织和缺陷复查要求；大量具体代码、修改建议、测试代码和文档由 AI 协助生成。不能将这些代码表述为完全人工逐行编写。

个人需要负责的部分是核对课程需求、理解数据库设计及跳转实现、审查 AI 建议是否合理、实际运行并判断测试结果、检查提交的报告与代码一致。此前的开发记录包含成功的本地测试结果，但本次文档精简未重新运行数据库和浏览器测试；最终提交时应保存最新结果。
