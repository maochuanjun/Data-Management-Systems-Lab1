# 操作指南

## 运行最新代码

当前工作区的连接配置已就位，直接执行 `make run`。首次克隆时在仓库根目录创建自己的配置：

```sh
cp -n .env.example .env # 首次克隆；已有配置时不会覆盖
chmod 600 .env
make run
```

项目根目录的 `.env` 是本项目唯一的本地配置来源，已被 Git 忽略，不应提交真实凭据。包装脚本从项目位置定位 `.env`，因此从其他目录调用也不会误读当前目录的文件；shell 中已经设置的同名变量优先。`MONGO_URI` 必须提供，`MONGO_DB` 默认是 `questionnaire_lab1`。

打开 `http://127.0.0.1:8080`。修改 Go 代码或网页文件后需重启：网页通过 `go:embed` 编译进程序，旧进程不会自动读取新文件。另一窗口的修复已保留为独立 Git 提交；启动时确保集合校验器和索引存在，无须另外执行数据迁移。

如果 8080 已被占用，可以使用 `PORT=8081 make run`。Go 程序不会自行读取 `.env`；需要绕过 Makefile 时，使用 `python3 scripts/with-local-mongo.py go run ./cmd/server`，或先把所需变量导入 shell 再执行 `go run`。已有问卷和回答仍在 MongoDB 中，重启不会清空。

## 创建和发布

1. 点击“没有账号？注册”，输入用户名与密码，注册成功自动登录。
2. 点击“新建问卷”，设置标题、说明、截止时间、是否允许匿名与重复提交。
3. 选择题型并“添加题目”。四种题型均可必填；展开“填写限制”设置数量、文本长度或数字范围。
4. 多选恰好两项：把“至少选择”和“至多选择”均设为 2。年龄：数字题设置整数、最小值 0、最大值 120。
5. “保存草稿”继续编辑，或“保存并发布”。保存期间编辑器暂时锁定，失败后恢复并保留内容。
6. 发布后复制分享链接。题目和配置已锁定，需要修正时创建更正后的新问卷。

## 设置跳转

展开题目的“条件跳转”，添加条件、比较值和目标题目。选项旁显示稳定 ID，条件值填这个 ID；修改选项文字不会改变 ID。

| 题型 | 比较方式 | 示例 |
| --- | --- | --- |
| 单选 | 等于选项 | 选择“不参与”的选项 ID 后结束 |
| 多选 | 包含选项 / 包含全部选项 | 多值用英文逗号分隔选项 ID |
| 数字 | 等于、大于、大于等于、小于、小于等于 | 年龄小于 18 时跳到后续题目 |

按顺序匹配第一条规则，未命中进入下一题；目标只能为后续题目或结束。被跳过的必填题不要求作答，服务器只校验实际路径。文本题不设置条件跳转。

## 填写

填写者打开 `/survey/{id}` 后先登录，也可在登录页面注册后返回原问卷。逐题填写并“下一步”，错误答案会提示。“上一步”可以修改回答，改变分支后旧分支答案不会提交。

完成后可匿名提交（问卷允许时）。匿名仍要求登录；关闭重复提交的问卷，同一账号的匿名和实名提交共用一次机会。

## 统计和关闭

创建者在详情中“查看回答统计”，查看选择次数、回答份数、文本内容与数字平均值。可按题筛选；文本和数字内容可翻页。翻页刷新当前题目和顶部提交总数，刷新页面可更新全部题目。

允许重复时，同一人可能贡献多份回答；“份回答”不是去重人数。未提交的选填题不计入；明确提交空文本或空选项且通过校验时会计入。

点击“关闭问卷”后，填写者看到关闭提示，不能通过新的提交准入检查；到期也会拒绝新提交。已经通过最终检查的请求可能在并发关闭后完成写入，边界见 [设计说明](design.md)。
